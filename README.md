This project is a web application created to test deployment using Docker, Nginx, and a Synology NAS. It consists of a frontend, a backend, and an Nginx configuration for deployment. Service orchestration is managed using Docker Compose.

## Project Structure

- **backend/**: Contains the backend source code written in Python.
- **frontend/**: Contains the frontend source code written in HTML.
- **nginx/**: Contains the Nginx configuration for reverse proxy.
- **docker-compose.yml**: Configuration file to orchestrate the Docker services.
